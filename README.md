# media – Laufzeitdaten von Yt-tk

Dieser Branch enthält nur Daten, die das System selbst schreibt:
- `videos/` fertige MP4s (öffentliche Links für Buffer)
- `content/<ID>/` Skript, Untertitel, QA-Bericht pro Video
- `data/` Inventar, Trends, Statistik, Serien-Stand
- `reports/` Tagesberichte

Code und Anleitung: Branch `claude/faceless-video-automation-pc59ot`, Datei README.md.
